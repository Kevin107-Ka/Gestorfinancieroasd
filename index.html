⚠️ Definición del problema

Actualmente muchas personas llevan el control de sus gastos en notas, hojas de cálculo o registros separados. Esto dificulta saber cuánto dinero reciben, cuánto gastan y en qué categorías se concentra el mayor consumo. También puede generar datos repetidos, pérdida de información y poca claridad al momento de revisar el comportamiento financiero de un mes.

Tech-Express busca solucionar esta situación centralizando los movimientos en un solo sistema, permitiendo consultar la información de forma organizada y obtener un resumen al finalizar cada período.

🛠️ Propuesta de solución

Se propone desarrollar una aplicación web sencilla para registrar ingresos y gastos personales. Cada movimiento tendrá fecha, concepto, valor, categoría y método de pago, de forma que la información quede organizada y pueda ser consultada posteriormente.

El sistema calculará automáticamente el balance, los gastos por categoría y los porcentajes del período. Al finalizar el mes se podrán consultar gráficas y reportes, y exportar la información para trabajarla en Excel.

🔐 Seguridad del sistema
ValidaciónLos formularios revisarán que los datos obligatorios estén completos y que los valores sean válidos.
Base de datosLa conexión SQL se realizará mediante consultas preparadas para reducir riesgos de inyección SQL.
AccesoLos usuarios tendrán una cuenta y permisos definidos según el módulo que utilicen.
DatosLas contraseñas no se guardarán como texto plano; se almacenarán utilizando hash seguro.
SesionesLa aplicación controlará las sesiones y evitará mantener datos sensibles directamente en el navegador.
CopiasLa base de datos podrá respaldarse periódicamente para evitar pérdida de información.
